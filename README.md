📝 Kanban Task Manager
A dynamic Board application that helps users manage tasks through different stages of a project. This project was developed as a final graduation project for a JavaScript course, focusing on real-world application of DOM manipulation, asynchronous programming, and interactive UI/UX.

🚀 Key Features
➜ Dynamic Fetching: Load tasks in real-time from a remote API (MockAPI).

➜ Drag & Drop System: Smooth task movement between columns with automatic sorting.

➜ Progress Tracking: Real-time progress bars for each department.

➜ Optimistic UI & Rollback: Immediate UI updates with a server-sync fallback mechanism.

➜ Toast Notifications: Professional feedback for successful or failed operations.

🛠️ Technologies Used
✦ HTML5 & CSS3: For structure and advanced styling (Flexbox/Grid).

✦ Modern JavaScript (ES6+): Using Async/Await, Fetch API, and Array Methods.

✦ MockAPI: To simulate a RESTful backend.

✦ Google Fonts: Poppins for a modern typography.

🏗️ Technical Highlights

1. Drag & Drop Logic
   The app uses the HTML5 Drag and Drop API to handle complex interactions. It calculates the mouse position to determine exactly where to insert the task within a column.

2. Error Handling & Rollback
   If a server update fails, the application automatically reverts the task to its original column and shows an error notification, ensuring data integrity.

📖 How to Run
↳ Clone the repository.

↳ Open index.html in any modern web browser.

↳ Start dragging tasks!
